# Turbo Circuito 3D

Jogo de corrida 3D feito com [Three.js](https://threejs.org/), num único arquivo HTML. Corra 3 voltas contra 3 carros controlados pela IA e tente chegar em primeiro.

## Como jogar

Abra o `index.html` no navegador (precisa de internet para carregar o Three.js) ou acesse a versão publicada no GitHub Pages.

| Tecla | Ação |
|---|---|
| `W` / `↑` | Acelerar |
| `S` / `↓` | Frear / ré |
| `A` `D` / `←` `→` | Virar |
| `Shift` | Turbo |
| `C` | Trocar câmera |
| `P` | Pausar |
| `M` | Ligar/desligar som |
| `R` | Reiniciar |

No celular aparecem botões na tela.

## Recursos

- Pista fechada com zebras, muros, área de escape, pórtico de largada e arquibancada
- 3 adversários com IA que freiam nas curvas e fazem ultrapassagens
- Turbo com recarga, velocímetro, minimapa, tempos de volta e melhor volta
- Som de motor gerado com Web Audio
